사용법 및 문의
  • 앱으로 실행 (주소창 숨김)
    PC주소창 우측 앱 설치 아이콘 클릭 (또는 F11 전체화면)
    아이패드Safari 공유 → 홈 화면에 추가
  • 화면 이동: Space + 드래그 (태블릿은 두 손가락 터치)
  • 직선 · 점선: Shift + 드래그로 직선, 필기바 펜 길게 누르기로 점선
  • 캔버스에 고정: 문제·그래프 배치 후 S 키(스탬프)로 배경에 고정
  • 스티커: 조건·정답을 가려두면 공유받은 학생도 직접 눌러 확인 가능
  • 전체 메뉴 숨김: H 키로 모든 메뉴를 숨기고 캔버스만 표시
  • 녹화 시작 · 정지: 우측 녹화 아이콘으로 시작, 녹화 중 다시 눌러 일시정지 · 종료
  • 슬라이드별 자동 구분: 영상은 슬라이드마다 나뉘어 저장되며, 녹화를 켠 채 페이지를 넘겨 연속 촬영해도 슬라이드별로 자동 분할
  • 재녹화 덮어쓰기: 슬라이드당 영상 1개만 유지되므로, 같은 페이지에서 다시 녹화하면 기존 영상 위에 덮어쓰기
  • 공백 자동 방지: 녹화 중 PDF 창을 열어 다음 문제를 고르거나 다른 창으로 이동하면 자동 일시정지되어 빈 시간이 녹화되지 않음
  • 용도별 골라 공유: 내보내기 체크박스로 수업 전엔 문제만, 수업 후엔 필기 + 음성 배포
  • 링크 · QR 자동 반영: 보관함 원본 수정·저장 시 기존 공유 링크·영구 QR에 자동 업데이트
  • 순수 그래프 복사: 그래프 조작 후 Ctrl + C → 필기 제외 고화질 그래프만 복사 (한글·PPT용)
  • 기기 간 동기화: 로그인 시 모든 기기에 보관함 · 내 그래프 · 내 클립 · 단축키 자동 연동
