💡 Graphly 사용 안내 · 단축키 · 공지사항
STEP 1 · 수업 시작

✂️ 캡처 모드 vs 📄 페이지 모드 자동 확정

  • 파일 열기 / 드래그 앤 드롭: 좌상단 [📁 불러오기]에서 파일을 열거나, 캔버스 화면 위로 PDF·이미지 파일을 직접 끌어다 놓으세요.
  • ✂️ 캡처 모드 (문제 단위 발췌 수업): PDF 뷰어에서 문제를 드래그해 캡처하면 캡처 모드로 확정됩니다. 이후 우상단 캔버스바의 [+ ➔ 다음 캡처]로 새 캔버스에 문제를 계속 추가할 수 있습니다.
  • 📚 한 캔버스에 여러 문제 넣기: PDF 뷰어에서 [📚 여러 문제 캡처]를 누르고 문제를 캡처하면 이동 모드로 자동 전환됩니다. 다음 문제로 이동해 [✂️ 영역 캡처]를 반복한 뒤 [📥 캔버스에 삽입 (N)]을 누르면 한 캔버스에 접힌 카드(▸)로 차곡차곡 쌓입니다.
  • 🖼️ 이미지(PNG/JPG) 다중 드래그: 이미지 여러 장을 한꺼번에 끌어다 놓으면 캔버스당 1문제씩 펼쳐진 상태(▾)로 자동 생성되어 즉시 < > 버튼으로 넘기며 수업할 수 있습니다.
  • 📄 페이지 모드 (교재 순차 판서 수업): PDF 뷰어에서 [📄 이 페이지 열기]를 누르면 페이지 모드로 확정됩니다. 우상단 캔버스바의 [+ ➔ 다음 페이지] 버튼으로 뷰어를 열지 않고 즉시 다음 페이지 캔버스를 추가할 수 있습니다.
STEP 2 · 판서 & 문제 카드

✒️ 문제 카드 · 직선 보정 · 가림막 스티커 꿀팁

  • 카드 더블클릭 자동 도킹: 문제 카드나 그래프 카드 상단을 더블클릭(더블탭)하면 카드가 작게 접히면서 좌측 상단에 줄 맞춰 자동 정렬됩니다.
  • 카드 위 밑줄 필기 (✒️ 버튼): 카드 우상단의 [✒️] 버튼을 켜면 카드가 고정되어 지문 위에 바로 밑줄·형광펜 필기가 가능하며, 끄면 카드를 잡고 이동할 수 있습니다.
  • 반듯한 직선·밑줄 자동 보정 (Draw & Hold): 선을 그은 뒤 펜 끝을 0.4초간 멈추고 있으면 반듯한 수평선·직선으로 자동 보정됩니다.
  • 가림막 스티커 (🟨): 우측 필기 리모컨의 스티커 도구로 빈칸이나 핵심 조건을 드래그해 가려두고, 수업 중 원터치(클릭)로 열었다 닫으며 판서할 수 있습니다.
STEP 3 · 실시간 그래프 & 녹화

📈 실시간 비율관계 역산 그래프 & 🎙️ 음성 동기화 녹화

  • 극점·변곡점 드래그 조작: 좌측 [📈 그래프]를 눌러 삼차·사차·초월함수의 조절점을 펜이나 마우스로 끌면 수능 비율 관계($2:1$, $1:\sqrt{3}$, $3:1$)를 100% 보존하며 실시간으로 개형이 변합니다.
  • 그래프 캡처 카드 & 타임머신 복구: 우상단 [📸 그래프 캡처]로 원하는 영역을 드래그하면 칠판에 그래프 카드(#1, #2...)로 부착되며, 카드의 [🔄] 버튼을 누르면 언제든 당시의 실시간 그래프 상태로 되돌아가 재조작할 수 있습니다.
  • 🎙️ 음성+필기+그래프 실시간 동기화 녹화: 우측 [🎙️ 녹음]을 켜고 수업하면 목소리와 필기 획·레이저 포인터·그래프 조작이 시간축으로 기록되어 [📤 내보내기]에서 링크 하나로 학생에게 공유할 수 있습니다.

Graphly v2.0 정식 출시 및 수업 모드(캡처/페이지) 동선 최적화 안내

실전 수업 환경에서 가장 많이 쓰이는 [✂️ 캡처 모드]와 [📄 페이지 모드]가 첫 행동에 따라 자동 확정되도록 개편되었으며, 축소 상태에서도 깨지지 않는 4.8x~6.0x 벡터 초고해상도 문제 캡처 엔진이 적용되었습니다.

기기 세팅 팁 상시 안내

아이패드 · 갤럭시탭 · 액정타블렛 필기 시 손바닥 터치 방지 안내

태블릿에서 펜으로 필기할 때 손바닥이 먼저 닿아 화면이 움직이는 경우, [⚙️ 설정 ➔ 필기 중 한 손가락 이동] 토글을 꺼두시면 펜으로만 필기되고 두 손가락으로만 화면 이동·확대가 작동하여 오작동 없이 쾌적하게 판서하실 수 있습니다.

교재 제작 팁 상시 안내

한글(HWP) · 파워포인트(PPT) 고화질 교재 삽도 1초 넣기

그래프 모드에서 개형과 보조 수선·라벨 세팅을 마친 뒤 키보드 Ctrl + C(또는 우상단 내보내기 ➔ 클립보드 복사)를 누르고 한글이나 PPT 문서에서 Ctrl + V를 누르면 여백이 자동 크롭된 출판급 고해상도 이미지가 즉시 삽입됩니다.
